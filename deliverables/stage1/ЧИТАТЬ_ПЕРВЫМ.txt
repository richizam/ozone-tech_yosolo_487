ВИДЕО И СЫРЫЕ ДАННЫЕ ПРОГОНОВ

Структура папок ниже ПОВТОРЯЕТ пути, указанные в отчёте
(раздел «Приложение А. Видеодемонстрация»). Любой путь вида
isaac_evidence/... из отчёта открывается здесь один в один.

  isaac_evidence/
    demo_sortmaster.mp4              сводный ролик, 1 мин 50 с
    twin_videos/                     MuJoCo-твин: номинал, пограничный
                                     набор, заклинивание
    xbelt/
      videos_final/                  основные прогоны Isaac Sim:
                                     sensor, edge_small_items, route_B/C/D,
                                     b_transfer, mech_tilt_C, fault_recovery,
                                     fault_tray, презентационные планы
        showcase_v5/                 та же евиденция, ревизия showcase
      perception/                    доказательства перцепции:
        perception_demo.mp4          сводный ролик панелей
        panels/, panels_edge/,       отдельные панели и сырые облака
        panels_hex/, sensor/,        точек (.npy) по наборам
        edge_small_items/,
        unknown_shapes/,
        unknown_shapes_final/,
        hex_probe/
      proof_pack/                    механика before/after
  validation/
    runs/                            видео прогонов MuJoCo-твина

================================================================
ГДЕ КОД И ЖУРНАЛЫ
================================================================

Весь код, README с инструкцией запуска, итоговый отчёт, а также
консолидированные сводки и сырые журналы прогонов (matrix_summary.json,
summary.json, events.csv по каждому прогону, validation_report.md,
classification_pr.md, панели перцепции в PNG) находятся в репозитории:

  https://github.com/hackathonsrus/ozone-tech_yosolo_487

Каждое число отчёта можно перепроверить прямо в репозитории,
не скачивая ничего отсюда.

Воспроизведение:
  python -m cell.validate                     MuJoCo-твин, 22/22 прогона, CPU
  bash isaac/run_matrix.sh <out>              матрица Isaac, GPU
  python tools/expert_check.py model.stl      проверка своего STL
