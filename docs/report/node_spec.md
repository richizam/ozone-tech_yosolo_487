# Спецификация узлов исполнительной части

> Генерируется `tools/make_node_spec.py` из `cell/params.py` — единого
> источника геометрии обеих симуляций (Isaac Sim и цифрового
> двойника MuJoCo). Числа в таблице по построению совпадают с
> валидированной моделью.

| Узел | Исполнение | Ключевые параметры |
|---|---|---|
| **Подающий конвейер A** | лента 500 мм, верх 700 мм | скорость 1.0 м/с (ФИКС. по ТЗ, не останавливается); нож-передача 15 мм на x=6.90 м |
| **Накопитель / эскейпмент** | 2 стоп-шибера с демпфирующей накладкой | предгейт x=5.35, эскейпмент x=6.35; метрирование по одному товару под темп сортера; контакт 2.5–3.4g << транспортной нормы |
| **Зона измерения** | 3× RTX depth + макро-головка (двух-диапазонная метрология) | верхняя 2.20 м + 2 боковых профилировщика; макро-головка для мелких (пол сертификации 10.8 мм); слияние многократных чтений |
| **Тилт-лоточный сортер** | 9 кареток, шаг 600 мм, замкнутая трасса 5.4 м | цепь 0.5 м/с (позиционное серво); лоток 590×620 мм V-профиль 2°; ось наклона 616 мм |
| **Привод наклона** | серворедуктор на хребтовой балке каретки | момент 150 Н·м (из массового расчёта); скорость 160°/с; рабочий наклон ±38°; предел шарнира ±46°; задержка команды 40 мс |
| **Индукция (передача A→лоток)** | расчётная точка посадки x=7.01 м | перепад 60 мм, полёт 110 мс; синхронизация выпуска с конкретной кареткой; учёт качения круглых (a_roll/a_slide=0.42) |
| **Гравитационные лотки C / D / REVIEW** | склиз 32°, ширина 700 мм | кромка z=395 мм; лабиринтное горло (щёки + фаска 20 мм); тормозная накладка в приёмнике; боковые рейлинги с отступом 90 мм от кромки |
| **Наклонный конвейер B** | лента 620 мм, 0.42→0.70 м | скорость 0.9 м/с; подъём 16.6° удержанием трением (в B только некруглые по правилам) |
| **Инфид сортера B** | лента 500 мм, верх 700 мм (ФИКС. по ТЗ) | x=8.4 м, 1.0 м/с, на север к основному сортировщику |
| **Ролл-кейджи C / D** | 1200×800×800 мм (по ТЗ), открыты сверху | свободное размещение; проёмная стенка с рамкой под склиз; контроль вместимости 60% |
| **Манипулятор разбора** | UR-класс 6-DOF, база (8.10, 2.42) | разбор нештатных ситуаций через проём кейджа; коридор переноса z=1.22 м; аудит столкновений — 0 нарушений |
| **Кинематика каретки** | хребтовая балка + вал Ø16 + сёдла + серьги | непрерывная силовая цепь: звено цепи → балка → сёдла → вал → серьги лотка; визуальный аудит зазоров: 0 пересечений (64→0 после перестройки) |
| **Аварийные поддоны флангов сброса** | лотковые поддоны с бортами вдоль обоих флангов | верх 300 мм; южный борт 120 мм + демпфирующая накладка; воротник 8 мм вокруг пьедестала манипулятора; вотчдог поддона → вызов оператора (пол конструктивно недостижим) |
