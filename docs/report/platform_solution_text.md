SortMaster — программно-аппаратный комплекс сортировки, выполненный
полностью в симуляции ДВУМЯ физическими движками из одного источника
параметров: NVIDIA Isaac Sim 6.0.1 (PhysX + RTX-сенсоры в контуре) и
MuJoCo (детерминированный твин, воспроизводим без GPU одной командой
docker compose up).

Классификация — метрология, а не чёрный ящик: 4 RTX-глубинные камеры
меряют товар В ДВИЖЕНИИ (лента 1 м/с не останавливается), правила
постановки применяются к измеренной геометрии с охранными полосами
измерителя (куб 11 мм честно B через макро-камеру GSD 0.4 мм, куб
10 мм — C). Круг в сечении — развёртка сечений по 12 осям: строгое
надмножество трёх проекций, всегда в безопасную сторону.

Исполнение — линейный tilt-tray сортировщик: эскейпмент, синхронная
посадка на лоток, гравитационный сброс, ролл-кейджи стандартной тары.
Ноль прямых записей скорости товару — freight движется только
контактной физикой.

Подтверждение: матрица Isaac 15 прогонов GATES PASS (номинал 1.0/1.0,
0 опасных, 0 на пол, margin 1.05 с, прогон официальной каденции
подачи), твин 22/22 PASS (235 товаров), precision(B)=1.0 на 159
решениях включая атакующий набор. Каждый отказ — на спроектированный
безопасный терминал; эксперт воспроизводит обе матрицы и прогоняет
СВОЙ STL через оба движка (tools/expert_check.py).
